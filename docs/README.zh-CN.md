# RuCorpus 开源软件版

这是可供其他团队独立部署的平行语料库系统，使用 MIT 许可证。仓库只发布代码、空数据库迁移、配置模板、技术文档和人工构造的测试；不发布实际语料、实际标注记录、账号数据库、密钥、服务器配置或恢复包。

系统以俄语为主：pymorphy3 提供俄语词形还原，Natasha 提供部分俄语句法规则。英语可复用基础词语/短语/前缀检索、平行阅读、可配置标注体系与导入导出，但没有英语时态、单复数或词形还原；例如 `walk` 不自动匹配 `walked`，需要用 `walk*`。法语和西语支持重音字母及两类撇号，保留重音差别。界面和表格表头目前仍为中文。

## 从空库开始

完整命令见根目录 [README](../README.md)。准备 Python 3.12、Node.js 22.12+，安装依赖，运行数据库迁移，再通过 `python manage.py create_admins administrator` 输入自己的密码。没有预置账号、默认密码或正式语料。启动前后端后，管理员先新建子库，再导入自己有权使用的文本。

子库的 `source_lang`、`target_lang` 和版本 `lang` 可填写 `ru`、`zh`、`en`、`fr`、`es` 等。标签体系可自己设计；新增标签不代表内置算法自动理解其含义。

## 数据与自动标注

[语料数据结构与 AI 自动标注开发指南](../DATA_ANNOTATION_GUIDE.md) 详细说明作品、版本、译者元信息、段落、对齐句组、句对、标注项组及标注项的字段、约束和导入导出语义。只有原文时的切句与 AI 结果中间格式是开发规范，需要适配器；当前系统不会一键生成译文或自动对齐任意文章。

旧系统的 SQL 提取、原文修复、真实例句、固定子库 ID 和数据清理迁移未包含在开源版。首页结构图为无正文的示意图，检索建议来自当前安装实例的元数据。

内置 `ai_annotate --corpus ID` 只刷新指定子库中内置 method 的结果；不指定 ID 则处理全部子库。新算法应使用独立 method 名，并自行管理批次与撤销。内置规则可能更正少数人工标签，运行前应备份自己的数据库。中文成语词表不随仓库发布；可用 `RUCORPUS_IDIOMS_PATH` 配置自行取得授权的词表，未配置时该检测范围较小。

## 自定义与部署

复制 `frontend/.env.example` 为 `frontend/.env.local`，设置站点名称及英文副标题，重新构建即可。`favicon.svg` 为单色图标，界面随主题变色。引用页面是通用的软件与数据出处说明；部署自己的语料时应补充自己的版权和引用信息，不强制引用某个未使用的语料库论文。

部署、备份、回滚和重建步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。MIT 允许修改、商用与再分发，需保留许可证和版权声明；它不覆盖用户导入的文学作品、译文、研究标注或词表。
